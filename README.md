แพลตฟอร์มการเรียนรู้การเขียนโปรแกรมภาษา Python ภาษาไทยแบบ Interactive ที่รองรับการจัดการเรียนการสอนในชั้นเรียนจริง พร้อมระบบครูผู้สอน ห้องเรียน และ AI โค้ชวิเคราะห์พัฒนาการผู้เรียนรายบุคคล

## ✨ ฟีเจอร์ใหม่ในเวอร์ชัน Classroom Edition (v2.0)

### 👩‍🏫 1. ระบบสำหรับครูผู้สอน (Teacher Portal)
- **ระบบสมัครสมาชิกและเข้าสู่ระบบของครู:** ครูสามารถลงทะเบียนด้วยอีเมลและรหัสผ่านที่เข้ารหัสความปลอดภัยระดับสูง
- **สร้างและจัดการห้องเรียน (Classrooms):**
  - สร้างห้องเรียนได้ไม่จำกัด (เช่น วิทยาการคำนวณ ม.4/1, ม.4/2)
  - ระบบจะสร้าง **รหัสห้องเรียน 6 ตัวอักษร (Classroom Code)** เช่น `SKF58X` พร้อมปุ่มคัดลอกลิงก์ให้นักเรียนเข้าได้ทันที
- **จัดการ Google Gemini API Key ของครูผู้สอน:**
  - ครูสามารถใส่ Gemini API Key ประจำห้องเรียนได้เพียงครั้งเดียว โดยคีย์จะถูกจัดเก็บและเข้ารหัสอย่างปลอดภัยที่ฝั่ง Server
  - **ความปลอดภัยสูงสุด:** คีย์จะไม่รั่วไหลไปยังเบราว์เซอร์ของนักเรียน (ผ่านระบบ Backend Proxy)
  - นักเรียนในห้องเรียนทุกคนสามารถเรียกใช้ AI ช่วยตรวจโค้ดได้ฟรี โดยใช้โควตา API Key ของคุณครู
- **แดชบอร์ดติดตามความคืบหน้า (Class Progress Matrix):**
  - แสดงรายชื่อนักเรียนทุกคนแบบเรียลไทม์ (เลขที่, ชื่อ-นามสกุล, คะแนน XP, จำนวนบทเรียนที่ผ่าน)
  - ตารางสถานะรายบทเรียน (ผ่านแล้ว / กำลังทำ / ยังไม่เริ่ม)
- **จุดเน้นที่ต้องพัฒนา (Focus Areas & Error Analytics):**
  - วิเคราะห์ประเภทข้อผิดพลาดที่นักเรียนในห้องพบบ่อยที่สุด เช่น `SyntaxError`, `IndentationError`, `NameError`, `TypeError`
  - จัดอันดับโจทย์ข้อที่นักเรียนติดขัดสะสม (Bottleneck Lessons)
  - **AI Teaching Insights:** สรุปบทวิเคราะห์เชิงครุศาสตร์ แนะนำว่าครูควรเน้นย้ำหรือทบทวนเรื่องใดในคาบเรียนถัดไป
- **วิเคราะห์นักเรียนรายบุคคล (Individual Student Diagnostics & Code Inspector):**
  - ตรวจดูโค้ดจริงที่นักเรียนแต่ละคนเขียนส่งในแต่ละข้อ พร้อมผล Output และ Error
  - บทวิเคราะห์ AI ประเมินระดับทักษะ (Novice / Intermediate / Advanced), จุดแข็ง, จุดที่ต้องปรับปรุง, และข้อแนะนำในการโค้ชเฉพาะบุคคล
- **ส่งออกรายงานคะแนน (Export CSV):** ดาวน์โหลดคะแนนและสถิติเป็นไฟล์ CSV รองรับภาษาไทยใน Microsoft Excel ได้ทันที

### 🎒 2. ระบบสำหรับนักเรียน (Student Experience)
- **เข้าห้องเรียนสะดวกรวดเร็ว:** นักเรียนเข้าผ่าน `join.html` หรือคลิกลิงก์ที่คุณครูแชร์ให้ เพียงกรอกรหัสห้องเรียน 6 หลัก + เลขที่ และชื่อ-นามสกุล (ไม่ต้องจำรหัสผ่าน)
- **ใช้ AI โค้ชฟรี:** ไม่ต้องมี Gemini API Key ส่วนตัว เพราะระบบจะดึงโควตาของห้องเรียนมาใช้โดยอัตโนมัติ
- **โหมดเรียนรู้เดี่ยว (Standalone Mode):** ผู้เรียนทั่วไปที่ไม่ได้อยู่ในห้องเรียนยังคงสามารถเข้าศึกษาและรัน Python ในเบราว์เซอร์ผ่าน Pyodide ได้ตามปกติ

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. ความต้องการของระบบ
- Node.js version 18 ขึ้นไป (แนะนำ Node.js v20 หรือ v22 ซึ่งมี Built-in SQLite ในตัว)

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. เริ่มต้นเปิดเซิร์ฟเวอร์
```bash
npm start
```
หรือโหมดพัฒนา (Auto-reload):
```bash
npm run dev
```

### 4. การเข้าใช้งานผ่านเว็บเบราว์เซอร์
- **หน้าหลัก (Home):** [http://localhost:3000](http://localhost:3000)
- **สำหรับนักเรียน (เข้าร่วมห้องเรียน):** [http://localhost:3000/join.html](http://localhost:3000/join.html)
- **สำหรับครูผู้สอน (เข้าสู่ระบบ/สมัครสมาชิก):** [http://localhost:3000/teacher-login.html](http://localhost:3000/teacher-login.html)
- **แดชบอร์ดครูผู้สอน:** [http://localhost:3000/teacher-dashboard.html](http://localhost:3000/teacher-dashboard.html)
- **สนามเด็กเล่นไพทอน (Playground):** [http://localhost:3000/playground.html](http://localhost:3000/playground.html)
